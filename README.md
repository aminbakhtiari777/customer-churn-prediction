Customer Churn Prediction

This is a machine learning project for predicting customer churn using customer service data.

The goal is to predict whether a customer is likely to leave the company or stay.

## What I practiced

- Loading a real business dataset
- Data cleaning
- Handling missing values
- Converting text columns into numerical features
- One-hot encoding
- Train/test split
- Training a Random Forest classifier
- Model evaluation
- Understanding accuracy, precision, recall, and confusion matrix
- Saving the trained model

## Tools used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Model

- Random Forest Classifier

## Result

The model achieved around 78% accuracy.  
The recall for churn customers was lower, which shows that accuracy alone is not enough for business machine learning projects.
